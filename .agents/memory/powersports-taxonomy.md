---
name: Powersports taxonomy
description: How motorcycle, ATV, and UTV listings should be classified without fragmenting marketplace filters.
---

Keep `Motorcycles`, `ATV`, and `UTV` as the listing subcategories. Add makes as manufacturer-prefixed model choices within the relevant vehicle type rather than adding each powersports make beside car brands.

**Why:** A make such as Can-Am spans ATVs and UTVs. Making both the vehicle type and the manufacturer competing subcategories fragments equivalent listings and makes browsing inconsistent.

**How to apply:** When adding a powersports make or model, place it in every relevant vehicle-type model list. Keep the model optional so uncommon models can still be listed through the title and description.
