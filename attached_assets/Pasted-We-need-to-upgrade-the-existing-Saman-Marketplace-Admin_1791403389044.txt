2. CREATE A PERSISTENT ANONYMOUS ID

Every visitor/user should receive an anonymous analytics ID even before login.

Requirements:

- Generate a UUID on first use.
- Persist it locally on the device/browser.
- Reuse the same anonymousId on future visits.
- Do not generate a new anonymousId every page refresh.
- It should work on web and Capacitor iOS/Android.

When someone later signs in or creates an account:

Continue sending the same anonymousId together with their userId.

Do not discard the anonymous history.

This will allow us later to associate pre-login activity with registered users.

3. ADD SESSION TRACKING

Create a persistent sessionId.

A session should start when:

- the app/site becomes active and there is no active session, OR
- the previous activity was more than 30 minutes ago.

Do NOT create a new session for every page view.

Store:

- sessionId
- anonymousId
- userId if known
- startedAt
- lastActivityAt
- platform
- appVersion

Update lastActivityAt as activity occurs.
